# ひとことポスト自動投稿システム

『15秒のひとことポスト』の動画を、毎朝自動で「台本作成 → 音声 → 動画合成 →
YouTube投稿 → コメント投稿 → 成績記録 → ルール改善（PDCA）」まで行う仕組みです。
実行基盤は GitHub Actions、費用はすべて無料枠内です。

**設定方法は [SETUP_GUIDE.md](SETUP_GUIDE.md) を見てください。**
コマンド操作は不要で、ブラウザのクリックとコピペだけで設定できます。

手動で今すぐ1本作りたいときは、リポジトリの「Actions」タブから
「hitokoto-post-daily」を選び、「Run workflow」を押してください。
